## 保留范围

原 React / Joy UI 组件系统、响应式网格、颜色主题、背景线条、介绍挥手动画、卡片风格、Experience 交错布局、房间整体格局、家具、灯光开关、音乐控制、相机动作与飞行飞机均延续原项目。未显示的旧项目辅助组件与图片未进行无意义的大规模清理。

`prepare-room.mjs` 校验原始场景 SHA-256，修改指定对象后深比较其他顶层房间对象，确认内容完全一致；编码结果还做无损解码验证。桌子高度与猫的路线使用同一个场景坐标系，先在桌外抬升再越过桌沿。

## 为完成迁移所需的附带改动

- 原 Travel Map 是作者托管的跨域网页，无法清空其数据；因此替换 iframe 的内容为本地 Leaflet 地图，保持全屏地图与原退出标识。地图/卫星切换、拖动、缩放可用。
- Spline 场景本地保存，以便修改照片和猫，也避免继续依赖作者的可变远程场景。首页房间缩略图同步更新为真实新截图。
- 删除作者 Firebase 部署目标，添加构建检查、News 定时更新与可选 GitHub Pages 工作流；不向原作者项目部署。
- 资源路径与路由支持 `/personal-website/` 子目录；补充直接打开子页面的房间载入及场景下载错误提示。
- 修正原音乐卸载清理和播放失败处理，避免退出房间后仍播放。
- News 的筛选栏允许窄屏换行。

## 保留的上游限制

原有依赖树存在 npm audit 报告的已知告警，本次未进行跨项目依赖升级，以控制迁移范围。构建产物是静态网站；原 Spline 运行时/物理模块仍较大。Spline 对 Blob 预载地址会发出文件扩展名提示，场景实际载入正常，属原有加载方式的提示。地图瓦片和定时抓取依赖外部服务；历史数据在源不可用时仍可浏览。

GitHub Pages 托管是可选配置，尚需按 README 开启；仓库提交和每日资料归档不依赖开启 Pages。

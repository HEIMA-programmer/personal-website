# Room landscape photography

Two independent color landscape collections replace the previous six black-and-white archive photographs. Each original Spline frame now contains **16 photographs**, all downloaded locally from Wikimedia Commons Featured Pictures. No image is presented as Yanbin's own photography.

These are curated photographs by the credited photographers, not personal travel photographs by Yanbin Xu. Each file retains its individual license. The only changes made here are proportional resizing to a maximum of 768 pixels and JPEG encoding; photographs are not cropped, recolored or generated. The resized CC BY-SA photographs are distributed under the same CC BY-SA version as their source.

The optimized textures total 3.18 MB. Images use progressive JPEG, Pillow quality 76, and a maximum long side of 768 pixels; aspect ratios are preserved against the original ivory mat. The scene embeds these local textures, so viewing the room does not depend on an image-host request. No browser imaging dependency was added.

## Collections and individual credits

Source and license metadata were retrieved from Wikimedia Commons' official image-information API on 2026-10-27. The linked file pages identify each creator and the precise license. The resized derivatives retain each corresponding CC BY-SA license; the two public-domain/CC0 images retain their recorded status.

## Scene behavior and maintenance

The original Spline Start → Transition mechanism performs the crossfades. The two collections have independent periods: 144 seconds for the horizontal frame and 176 seconds for the vertical frame. Both loop over all 16 photographs. The original frame meshes, furniture, camera and interactions are preserved.

collection.json contains individual authors, licenses, source URLs, original sizes, local sizes and SHA-256 checksums. The room generator validates each checksum before embedding the image. To change a photograph, choose a compatible reusable image, update its source/author/license and checksum in the manifest, update this table and credits.html, then regenerate with node scripts/prepare-room.mjs. Preserve attribution and the source license for any replacement. The public [credits page](credits.html) is linked from the website footer.

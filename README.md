# Yanbin Xu's personal website

Personal academic homepage adapted directly from [Leonard Niehaus's personal-website](https://github.com/niehaus1301/personal-website), retaining the original React / Joy UI design and Spline room.

Upstream baseline: `c5198583b41468baf4dee184e53f6fdac4120af5`. The source history is retained with historical `.env` files removed because GitHub detected an old Mapbox secret in upstream history. Only the current public website configuration is restored in a new commit. `upstream` points to the template and `origin` to [HEIMA-programmer/personal-website](https://github.com/HEIMA-programmer/personal-website).

## Run locally

Requires Node.js 22 or later.

```sh
npm ci --legacy-peer-deps
npm run dev
```

Open the URL printed by Vite. `--legacy-peer-deps` is retained because the template mixes React 19 with dependencies declaring older React peer versions.

```sh
npm test
npm run build
npm run preview
```

The build output is `dist/`. No backend service is required. The browser downloads the local Spline scene and local News archives. Mapbox uses the owner's public browser token from the ignored `.env.local` during local development, and the repository Actions variable `VITE_MAPBOX_TOKEN` during GitHub builds. The token is not committed to source. Map tiles need an Internet connection and are subject to the Mapbox account's usage limits.

## Daily research updates

`Update research news` runs in GitHub Actions daily at 01:23 UTC (09:23 China Standard Time), and can also be run manually. It fetches bioRxiv and Europe PMC / PubMed metadata, scores topical relevance, classifies papers and commits an immutable daily edition. Dates are shown in UTC. Historical editions begin with the first actual collection on 2026-10-27; no past editions are fabricated.

The initial edition contains 12 real papers and remains unchanged as a historical snapshot. The publication catalog extends back to October 1, 2026 and continues to grow without a fixed paper-count cap. Each page shows up to 12 matching papers; previous/next and page selection replace the cards and reset their horizontal position. The compact toolbar exposes date and topic filters, with additional filters available on demand. Cards display complete titles; abstracts remain in Details. Automatic relevance filtering is not an assessment of scientific quality. Preprints and journal articles are labelled separately; full metadata, abstracts and licensed article figures are available in the details view.

For a manual local update:

```sh
npm run news:update
```

GitHub Actions must remain enabled with repository content-write permission. Schedules may run late, and GitHub can suspend scheduled workflows on inactive public repositories. An outage retains the existing archive and reports incomplete source coverage instead of inventing results.

## Optional GitHub Pages hosting

The repository is prepared for GitHub Pages but does not automatically enable hosting. The previous author's Firebase deployment has been removed.

1. In the repository, open Settings → Pages and select **GitHub Actions** as the source.
2. Under Settings → Secrets and variables → Actions → Variables, set `DEPLOY_PAGES` to `true`.
3. Run **Deploy GitHub Pages** from Actions.

The workflow builds for `/personal-website/`. It also responds to completed daily-news workflows, so scheduled updates reach the hosted website. A `404.html` fallback supports direct room/map/terminal URLs. If using another host, configure SPA fallback and set `VITE_BASE_PATH` only when deploying under a subdirectory. Keep it unset for root-domain hosting.
